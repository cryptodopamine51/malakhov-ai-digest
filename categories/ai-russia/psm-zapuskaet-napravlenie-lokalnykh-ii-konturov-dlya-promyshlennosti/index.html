ПСМ запускает направление локальных ИИ-контуров для промышленности

Подготовлено редакцией Malakhov AI

CNews·11 июн.·2 минРоссия

11 июня 2026 года ПСМ, производитель энергосистем для ЦОД, анонсировал комплексную модель ИИ-инфраструктуры, объединяющую инженерно-вычислительную и ИИ-платформы в одном проектном контуре для корпоративных заказчиков.

Кратко

  • —ПСМ предлагает локальные ИИ-контуры — защищенную инфраструктуру внутри периметра компании.
  • —Решение включает три слоя: ИИ Base (инженерия), ИИ Cluster (GPU), ИИ Factory (платформа управления моделями).
  • —Компания выступает единым вендором, беря на себя ответственность за интеграцию всех этапов.
Глоссарий · 4 термина▾
локальный ИИ-контур
Защищенная инфраструктура внутри периметра компании, предназначенная для работы ИИ-сервисов без использования публичных облаков.
ИИ Base
Инженерный компонент решения ПСМ, включающий электротехническое оборудование, автоматику, системы охлаждения и безопасности в едином модуле.
ИИ Cluster
Вычислительный компонент, состоящий из графических процессоров (GPU) и системы хранения данных.
ИИ Factory
ИИ-платформа для управления моделями и разработки прикладных сценариев, входящая в состав решения ПСМ.

11 июня 2026 года ПСМ, производитель энергосистем для центров обработки данных, объявил о запуске нового направления — локальных ИИ-контуров для промышленных предприятий. Решение ориентировано на корпоративных заказчиков, которым необходимы собственные защищенные ИИ-сервисы без использования публичных облаков. По сообщению компании, локальный контур включает три взаимодополняющих компонента: ИИ Base (инженерная инфраструктура — электротехника, охлаждение, автоматика), ИИ Cluster (вычислительная мощность на основе графических процессоров и системы хранения данных) и ИИ Factory (ИИ-платформа для управления моделями и разработки прикладных сценариев).

Необходимость в таких решениях возникает из-за того, что для части крупных компаний публичные облака и внешние ИИ-сервисы не закрывают требования по защите данных, управлению доступом, отказоустойчивости и контролю над критичными процессами. Ранее заказчики вынуждены были собирать подобные проекты через множества подрядчиков, что размывало ответственность за интеграцию ИИ и создавало риски по срокам и стоимости. ПСМ становится вендором комплексного решения, в котором все ключевые слои локального ИИ-контура проектируются согласованно. При необходимости компания может включить в проект собственную газовую генерацию для компенсации энергодефицита.

Генеральный директор ПСМ Андрей Медведев отметил, что проникновение ИИ в производственные процессы ускоряется во всем мире, и уже через два-три года разница в производительности между бизнесом с ИИ и без него станет огромной. По его словам, компания стремится опережать запрос рынка, создавая инфраструктуру для лидерства предприятий в гонке за ИИ. Новое направление рассчитано на востребованные сценарии: корпоративные базы знаний, видеоаналитику, обработку документации и производственных данных.
