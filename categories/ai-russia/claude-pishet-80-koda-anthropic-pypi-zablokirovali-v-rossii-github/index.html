Claude пишет 80% кода Anthropic, PyPI пропал в России, GitHub тонет в ИИ-PR

Подготовлено редакцией Malakhov AI

Habr AI·10 июн.·3 минРоссияКод

С февраля 2025 года доля кода, написанного Claude в кодовой базе Anthropic, выросла с нескольких процентов до 80% — компания называет это началом рекурсивного самосовершенствования. Параллельно 1 июня российские разработчики на несколько часов лишились доступа к PyPI, а GitHub фиксирует 17 млн ИИ-сгенерированных pull request'ов в месяц.

Кратко

  • —80% кода в кодовой базе Anthropic пишет Claude — до запуска Claude Code в феврале 2025 года показатель был в районе нескольких процентов.
  • —9 июня вышел Claude Fable 5 — публичная версия модели Mythos, лучшей у Anthropic по инженерным задачам; до 22 июня доступна без доплаты.
  • —1 июня pypi.org был недоступен в России несколько часов — предположительно из-за блокировки по смежному IP, РКН причастность отверг.
  • —GitHub в марте 2026 фиксировал 17 млн ИИ-сгенерированных PR в месяц против 4 млн в сентябре 2025; в апреле 84% запросов в пике завершались ошибкой.
  • —NVIDIA выпустила Nemotron 3 Ultra: 550 млрд параметров, MoE-архитектура, Intelligence Index 48 — лидер среди американских open-weights моделей.
Глоссарий · 7 терминов▾
Рекурсивное самосовершенствование
Процесс, при котором ИИ-модели участвуют в создании и обучении следующих, более мощных версий себя, ускоряя цикл разработки.
MoE (Mixture of Experts)
Архитектура нейросети, в которой активируется только часть параметров при обработке каждого запроса — это снижает вычислительные затраты при сохранении общего числа параметров.
Frontier-модели
Наиболее мощные и передовые ИИ-модели на текущий момент, находящиеся на переднем крае возможностей отрасли.
PyPI
Python Package Index — центральный публичный репозиторий пакетов для языка программирования Python, через который устанавливается большинство библиотек.
Pull request (PR)
Запрос на слияние изменений кода в основную ветку репозитория; стандартный инструмент совместной разработки на GitHub.
Open-weights
Модель, веса которой открыто опубликованы и доступны для скачивания и локального запуска, в отличие от закрытых API-only моделей.
Intelligence Index
Сводная benchmark-метрика для сравнения языковых моделей по совокупности задач на рассуждение, кодинг и работу со знаниями.

4 июня Anthropic опубликовали статью When ИИ Builds Itself с внутренней статистикой, которая наглядно показывает, как быстро меняется разработка внутри самой компании. До запуска Claude Code в феврале 2025 года ИИ писал лишь несколько процентов кода в основной кодовой базе. Сегодня эта доля превышает 80%. За тот же период средний инженер Anthropic стал отгружать примерно в 8 раз больше кода в квартал.

Отдельные цифры говорят о качестве, а не только об объёме. На открытых задачах без заранее заданного решения Claude справляется в 76% случаев — в сентябре 2025 года показатель составлял 25%. Внутренняя модель Mythos Preview ускорила тренировочный код в 52 раза по сравнению с исходным benchmark. Claude Opus 4.5 в ноябре 2025 выбирал лучший следующий шаг в исследовательских сессиях чаще человека в 51% случаев; Mythos Preview в апреле 2026 — уже в 64%. Anthropic называет происходящее началом рекурсивного самосовершенствования: модели ускоряют создание следующих поколений моделей. Компания при этом выступает за механизм координации, который позволил бы приостановить разработку frontier-моделей при необходимости.

Через пять дней после публикации статьи, 9 июня, Anthropic выпустили Claude Fable 5 — первую публично доступную версию Mythos. До 22 июня модель доступна пользователям Pro, Max, Team и Enterprise-планов без доплаты, с 23 июня переходит на кредитную тарификацию. Модель позиционируется как лучшая у Anthropic по инженерным задачам, работе со знаниями и компьютерному зрению. В высокорисковых областях — кибербезопасность, биология, химия — предусмотрены жёсткие ограничения с откатом на Opus 4.8. Переход на кредитную модель после двухнедельного бесплатного периода фактически означает отказ от субсидирования инференса через подписку.

1 июня российские разработчики столкнулись с недоступностью pypi.org — основного репозитория пакетов для Python. Проблема затронула как локальную установку пакетов, так и облачные окружения. РКН свою причастность отверг; по всей видимости, pypi.org попал под блокировку по смежному IP-адресу. К вечеру доступ восстановился. Инцидент обнажил уязвимость разработческой инфраструктуры: даже кратковременная недоступность центрального репозитория блокирует CI/CD-пайплайны и локальную разработку одновременно.

GitHub публикует данные, которые отражают масштаб нагрузки от ИИ-агентов на платформу. В марте 2026 агенты генерировали 17 млн pull request'ов в месяц — против 4 млн в сентябре 2025. Использование GitHub Actions выросло с 500 млн минут в неделю в 2023 году до 2,1 млрд в начале 2026-го. В первую неделю апреля произошло пять отдельных инцидентов: Copilot не работал 2,7 часа, code search — 8,7 часов, время ожидания агентских сессий в пике доходило до 54 минут при норме 15–40 секунд, 84% запросов в момент пиковой нагрузки завершались ошибкой.

1 июня на Computex Дженсен Хуанг анонсировал Nemotron 3 Ultra, 4 июня NVIDIA выложила веса модели. 550 млрд параметров, 55 млрд активных (архитектура MoE с гибридным Mamba-Attention), более 300 токенов в секунду, по заявлению компании — в 5 раз быстрее предшественников и на 30% дешевле в инференсе. Intelligence Index составляет 48 — лидер среди американских open-weights моделей, хотя китайские конкуренты пока впереди: Kimi K2.6 набирает 54. Веса открытые, доступны через NVIDIA NIM; модель ориентирована на долгосрочное планирование и сложный кодинг в агентных сессиях.
