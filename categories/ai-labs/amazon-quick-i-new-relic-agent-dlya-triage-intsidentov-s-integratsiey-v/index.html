Amazon Quick и New Relic: агент для triage инцидентов с интеграцией в Asana

Подготовлено редакцией Malakhov AI

AWS Machine Learning Blog·9 июн.·1 минЛабораторииКод

Инженеры Amazon Quick и New Relic представили готовый шаблон агента для triage инцидентов, который объединяет сбор доказательств, анализ причин и создание задачи в Asana в одном диалоговом workflow. Агент использует пять инструментов New Relic для автоматического анализа алертов, влияния на пользователей, логов, транзакций и преобразования запросов в NRQL.

Кратко

  • —Агент на основе Amazon Quick использует встроенные коннекторы к New Relic и Asana для автоматизации triage инцидентов.
  • —Пять инструментов New Relic (от анализа алертов до NRQL-запросов) выполняют расследование по одному запросу.
  • —Внутреннее тестирование New Relic показало сокращение времени сбора доказательств при triage инцидентов.

Model Context Protocol — протокол для интеграции внешних инструментов с ИИ-агентами.
NRQL
New Relic Query Language — язык запросов для данных мониторинга New Relic.
MTTR
Mean Time to Resolution — среднее время решения инцидента.
Triage
Процесс первичной оценки и сортировки инцидентов для определения приоритетов реагирования.

Инженеры Amazon Quick и New Relic представили готовый шаблон агента для triage инцидентов. Он объединяет несколько этапов расследования в единый диалоговый workflow. Агент на основе Amazon Quick использует встроенные коннекторы к New Relic и Asana. По одному запросу, например «Checkout is slow and we are seeing server errors on checkout-service in production. Check the last 24 hours. Generate RCA brief», агент вызывает пять инструментов New Relic, собирает результаты и формирует краткое описание корневой причины (RCA) с ссылками на доказательства. Затем он создаёт отслеживаемую задачу в Asana для передачи следующей смене.

Пять инструментов New Relic, доступных через MCP-сервер, работают как независимые агенты: generate_alert_insights_report выявляет ключевые драйверы алертов, generate_user_impact_report оценивает радиус поражения, analyze_entity_logs находит сигналы ошибок, analyze_transactions определяет медленные или неудачные запросы, а natural_language_to_nrql_query преобразует запросы на естественном языке в NRQL и выполняет их. Агент решает, какие инструменты вызвать, в зависимости от запроса.

ИнструментНазначение
generate_alert_insights_reportОпределяет ключевые драйверы алертов.
generate_user_impact_reportОценивает радиус поражения — количество пользователей и сервисов.
analyze_entity_logsВыявляет сигналы ошибок и исключения.
analyze_transactionsИдентифицирует медленные или неудачные запросы.
natural_language_to_nrql_queryПреобразует запросы на естественном языке в NRQL и выполняет их.

Для инженерных руководителей снижение среднего времени решения (MTTR) — ключевой показатель эффективности. Внутреннее тестирование New Relic на собственных приложениях показало, что агент сократил фазу сбора доказательств при triage. Это ускоряет разрешение, снижает риск потери знаний между сменами и обеспечивает единый стандарт расследования для всей дежурной ротации.

Чтобы воспользоваться решением, необходима учётная запись Amazon Quick (Professional-подписка), New Relic и Asana. Настройка включает создание интеграций через консоль Amazon Quick, аутентификацию коннекторов и конфигурацию передачи задач. Полное описание шагов опубликовано в блоге AWS.
