ChatGPT запустил Projects — общие рабочие пространства с памятью и файлами

Подготовлено редакцией Malakhov AI

OpenAI News·10 апр. 2026 г.·2 минЛаборатории

OpenAI добавила в ChatGPT функцию Projects: выделенные пространства, где чаты, файлы и инструкции хранятся вместе и не теряют контекст между сессиями. Для корпоративных клиентов Enterprise доступно управление проектами на уровне всего воркспейса с разграничением прав.

Кратко

  • —Projects объединяют чаты, файлы и инструкции в одном месте — контекст не нужно повторять при каждом новом разговоре.
  • —Режим project-only memory изолирует проект: чаты внутри него не видят историю из других проектов.
  • —На поддерживаемых тарифах проекты можно открывать для совместной работы — все участники видят обновления в реальном времени.
  • —Администраторы Enterprise управляют общими проектами на уровне воркспейса и настраивают доступ через ролевые политики.
  • —Функция подходит для исследований, многоэтапных текстов, регулярных планёрок и любых задач с накапливаемым контекстом.
Глоссарий · 4 термина▾
project-only memory
Режим памяти, при котором ChatGPT учитывает только историю разговоров внутри текущего проекта, не обращаясь к чатам из других проектов.
role-based access controls
Система разграничения прав доступа, при которой каждый пользователь получает только те возможности, которые соответствуют его роли в организации.
LLM
Large Language Model — большая языковая модель, тип нейросети, обученной на текстах и способной генерировать связные ответы на запросы пользователя.
воркспейс
Корпоративное рабочее пространство в ChatGPT Enterprise, объединяющее всех сотрудников организации под единым аккаунтом с централизованным управлением.

С 10 апреля 2026 года пользователи ChatGPT получили доступ к Projects — выделенным рабочим пространствам, которые хранят чаты, файлы и пользовательские инструкции под одной «крышей». До этого каждый новый разговор с моделью начинался с чистого листа: чтобы продолжить работу над документом или исследованием, приходилось заново загружать файлы и объяснять контекст.

Проект создаётся через левое меню ChatGPT: пользователь задаёт название, добавляет файлы, прописывает инструкции и при необходимости переносит туда уже существующие чаты. Все последующие разговоры внутри проекта автоматически видят этот общий контекст — модель помнит, что уже обсуждалось, какие файлы загружены и какие правила заданы.

SituationHow a project helps
Ongoing researchKeeps notes, source files, and related chats together so you can build on earlier work
Writing and editingStores drafts, reference materials, and instructions in one place so revisions stay connected
PlanningOrganizes plans, ideas, and supporting documents around one goal
Learning a topicBrings together questions, study materials, summaries, and follow-up chats
Personal organizationHelps manage longer-running efforts like trip planning, job searching, budgeting, or major decisions
Shared collaborationGives collaborators access to the same files, instructions, and conversation history when sharing is available

Одна из ключевых настроек — project-only memory. Когда она включена, чаты внутри проекта могут ссылаться на другие разговоры того же проекта, но не видят историю из остальных пространств. Это полезно, когда нужно держать рабочие и личные задачи строго раздельно или когда несколько проектов касаются конкурирующих направлений.

Совместная работа доступна на поддерживаемых тарифах: участники проекта работают с одними и теми же файлами, инструкциями и историей переписки, а изменения отображаются в реальном времени. Для корпоративного сегмента — клиентов ChatGPT Enterprise — предусмотрен отдельный уровень управления: администраторы настраивают общие проекты на уровне всего воркспейса и разграничивают доступ через ролевые политики (role-based access controls).

Подобный подход к организации контекста уже встречался в других ИИ-ассистентах: Anthropic реализовала аналогичную механику в виде Projects для Claude, а Microsoft встроила постоянную память и организацию файлов в Copilot. OpenAI, судя по всему, ориентируется на тех же корпоративных пользователей, для которых разрозненные чаты давно стали узким местом при работе с LLM. Projects закрывает этот пробел, не требуя от пользователя переходить к сторонним инструментам управления знаниями.
