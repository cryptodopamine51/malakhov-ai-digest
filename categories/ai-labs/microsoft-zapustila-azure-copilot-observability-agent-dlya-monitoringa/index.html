Microsoft запустила Azure Copilot Observability Agent для мониторинга облачных систем

Подготовлено редакцией Malakhov AI

Microsoft Blogs·23 июн. 2026 г.·2 минЛабораторииИндустрия

Microsoft объявила о выходе в общую доступность Azure Copilot Observability Agent — инструмента на базе ИИ, который помогает операторам анализировать работу облачных систем и быстрее находить причины сбоев.

Кратко

  • —Azure Copilot Observability Agent стал общедоступен и развёрнут на платформе Azure Monitor.
  • —По опросу Microsoft и Material, 84% организаций отмечают рост сложности облачной инфраструктуры.
  • —Инструмент объединяет данные из логов, метрик и трасс, используя естественный язык для расследования.
  • —Заказчики сообщают об экономии до 250 человеко-часов в месяц за счёт автоматизации расследований.
  • —Решение знаменует переход к агентным операциям, где ИИ активно участвует в управлении системами.
Глоссарий · 2 термина▾
Агентная наблюдаемость (agentic observability)
Подход к мониторингу, при котором ИИ-агенты активно анализируют сигналы системы и помогают находить причины проблем, а не просто отображают метрики.
Azure Monitor
Платформа мониторинга Microsoft Azure, собирающая и анализирующая данные телеметрии из облачных и локальных сред.

Microsoft объявила о выходе в общую доступность Azure Copilot Observability Agent — инструмента на базе ИИ, который помогает операторам анализировать работу облачных систем и быстрее находить причины сбоев. Решение построено на платформе Azure Monitor и коррелирует сигналы от агентов, приложений, инфраструктуры и сервисов.

По данным опроса Microsoft и Material, 84% организаций отмечают рост сложности облачной инфраструктуры, причём 69% считают, что этот рост опережает возможности их текущих подходов к управлению. Проблема особенно остра в сферах безопасности, управления затратами и производительности. Как отмечается в блоге Microsoft, системы больше не выходят из строя изолированно — сбои возникают из-за взаимодействия между зависимостями, сервисами и средами, которые постоянно меняются в реальном времени.

Azure Copilot Observability Agent призван решить проблему разрозненности инструментов мониторинга. Он объединяет логи, метрики, трассы, топологию и операционный контекст в единую картину, сокращая время перехода от обнаружения проблемы к пониманию её корневой причины. Агентные возможности встроены непосредственно в рабочие процессы, что позволяет командам быстрее переходить от расследования к устранению инцидентов.

Представители компаний-заказчиков подтверждают эффективность решения. Например, Narmada Krishnaswamy, руководитель поддержки приложений и операций в KPMG, сообщила, что Observability Agent помогает ускорить разрешение инцидентов, переводя логи, метрики и трассы на понятный человеческий язык. По её словам, внедрение инструмента позволило вернуть около 250 человеко-часов в месяц, которые теперь направляются на поддержку новых приложений и функций. Владимир Гусаров, основатель PolicyVault, отметил, что агент даёт не просто информацию о том, что сломалось, но и чёткое понимание причин и дальнейшие шаги. Theus Hossmann, CTO Ontinue, подчеркнул, что инструмент ускоряет переход от сигнала к инсайту.

Запуск Observability Agent — часть более широкого перехода к агентным операциям (agentic operations), где ИИ не только помогает анализировать данные, но и активно действует: от понимания текущего состояния системы до непрерывного улучшения её поведения. В таком подходе наблюдаемость становится фундаментом, обеспечивающим агентов информацией для принятия решений. Для операторов это означает, что облачные системы можно не только мониторить, но и делать их более автономными и предсказуемыми.

Контекст: рост сложности облачной инфраструктуры и числа взаимосвязей между компонентами делает традиционные методы наблюдения недостаточными. Инструменты на основе ИИ, такие как Azure Copilot Observability Agent, предлагают новый уровень автоматизации, позволяя командам сосредоточиться на стратегических задачах вместо ручного сбора данных. Это тренд, который уже поддерживается и другими игроками, например, Google Cloud с Operations Suite и AWS с DevOps Guru, но Microsoft делает ставку на агентный подход и интеграцию с Azure Copilot.
