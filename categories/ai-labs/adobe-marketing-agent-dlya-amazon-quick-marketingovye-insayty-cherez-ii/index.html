Adobe Marketing Agent для Amazon Quick: маркетинговые инсайты через ИИ-диалог

Подготовлено редакцией Malakhov AI

AWS Machine Learning Blog·19 июн.·2 минЛабораторииКод

Adobe и Amazon Quick запустили интеграцию Adobe Marketing Agent, которая позволяет маркетологам получать аналитику кампаний, аудиторий и путей клиента на естественном языке через ИИ-чат. Решение использует протокол Model Context Protocol (MCP) для безопасного доступа к данным Adobe Experience Platform.

Кратко

  • —Интеграция использует Model Context Protocol для подключения ИИ-агента Amazon Quick к маркетинговым данным Adobe.
  • —Пользователи могут задавать вопросы о производительности кампаний, аудиториях, конфликтах пути и контенте.
  • —Встроенные средства контроля включают минимальные привилегии, аудит логов и проверку человеком рекомендаций с запуском.
  • —Настройка занимает 45–60 минут и требует Amazon Quick Enterprise, Adobe CX Enterprise и Adobe Experience Platform Agent Orchestrator.
  • —Adobe Marketing Agent предоставляет инструменты для мониторинга кампаний, планирования, анализа аудиторий, путей и конфликтов.

Model Context Protocol (MCP)
Открытый протокол, позволяющий ИИ-агентам безопасно подключать внешние инструменты и источники данных через стандартизированный интерфейс.
Adobe Experience Platform Agent Orchestrator
Компонент Adobe, управляющий ИИ-агентами и их доступом к данным, необходимый для работы Adobe Marketing Agent.

Adobe Marketing Agent для Amazon Quick — это интеграция, которая добавляет в ИИ-чат Amazon Quick возможность получать аналитику из Adobe Experience Platform. Маркетологи могут задавать вопросы на естественном языке, например: «покажи рейтинг аудиторий по лояльности» или «какие кампании конфликтуют по времени?». Система возвращает ответы, таблицы, графики или рекомендации, которые затем можно использовать для планирования кампаний.

Технически интеграция реализована через Model Context Protocol (MCP) — открытый стандарт, позволяющий ИИ-агентам подключать внешние инструменты. Amazon Quick выступает в роли клиента MCP, который обнаруживает инструменты на MCP-сервере Adobe, регистрирует их как действия и вызывает их во время диалога. Сервер Adobe проверяет запрос, обращается к авторизованным источникам данных Adobe и возвращает результат. Весь поток контролируется: применяются наименьшие привилегии, изоляция тенантов, аудит логов и обязательная проверка человеком для решений, влияющих на запуск кампании.

Группа инструментовОписание
Campaign review & monitoringВизуализация метрик кампаний для мониторинга и обзора
Campaign PlanningДоступ к данным охвата и прошлых кампаний для планирования
Audience InsightsРазмер аудитории, часто изменяющиеся сегменты, пересечения, атрибуты для роста
Journey InsightsАнализ существующих путей для мониторинга и корректировки
Journey Conflict AnalysisВыявление конфликтов путей до запуска для избежания пересечений

Adobe Marketing Agent предоставляет пять групп инструментов: мониторинг и обзор кампаний, планирование кампаний (охват, прошлые показатели), инсайты по аудиториям (размер, пересечения, часто изменяющиеся аудитории), инсайты по путям клиента (бизнес-результаты, корректирующие действия) и анализ конфликтов путей (обнаружение пересекающихся путей до запуска). Для использования требуется Amazon Quick Enterprise, один или несколько продуктов Adobe CX Enterprise (Real-Time CDP, Customer Journey Analytics или Journey Optimizer), а также лицензия Adobe Experience Platform Agent Orchestrator. Оценка времени настройки — 45–60 минут после готовности MCP-эндпоинта и учётных данных. Стоимость складывается из подписки Amazon Quick, лицензирования Adobe и инфраструктуры для MCP-сервера.

Появление такой интеграции — часть более широкой тенденции: вендоры enterprise SaaS всё чаще добавляют ИИ-агентов, работающих через естественный язык, чтобы снизить порог доступа к данным и аналитике. В отличие от встроенных BI-чат-ботов, решение на базе MCP позволяет подключать сторонние доменные инструменты (в данном случае маркетинговые) без глубокой кастомизации. Для российских компаний, использующих Amazon Quick, это может быть альтернативой проприетарным решениям, однако требует оценки ограничений по доступу к Adobe Cloud из РФ.
