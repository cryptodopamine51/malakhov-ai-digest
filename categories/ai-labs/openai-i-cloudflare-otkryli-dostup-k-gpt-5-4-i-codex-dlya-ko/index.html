OpenAI и Cloudflare открыли доступ к GPT-5.4 и Codex для корпоративных агентов

Подготовлено редакцией Malakhov AI

OpenAI News·13 апр.·2 минЛаборатории

GPT-5.4 и Codex теперь доступны миллионам корпоративных клиентов Cloudflare через платформу Agent Cloud — компании могут развёртывать ИИ-агентов, которые отвечают клиентам, обновляют системы и формируют отчёты в автоматическом режиме.

Кратко

  • —Cloudflare Agent Cloud интегрировала модели OpenAI, включая GPT-5.4, для корпоративных рабочих нагрузок.
  • —Codex harness доступен в Cloudflare Sandboxes, в ближайшее время появится и в Workers AI.
  • —API OpenAI обрабатывают более 15 млрд токенов в минуту, Codex используют 3 млн человек еженедельно.
  • —Среди клиентов интеграции — Walmart, Morgan Stanley, Accenture, BNY, State Farm и BBVA.
  • —Инфраструктура строится на Cloudflare Workers AI — платформе для запуска ИИ-моделей на периферии сети.
Глоссарий · 6 терминов▾
Agent Cloud
Платформа Cloudflare для развёртывания ИИ-агентов, которые автономно выполняют корпоративные задачи на базе моделей OpenAI.
Workers AI
Инфраструктура Cloudflare для запуска ИИ-моделей на периферии сети (edge), что снижает задержку для конечных пользователей.
Codex
Инструмент OpenAI на базе языковой модели, предназначенный для автоматизации задач программирования и разработки.
Edge-вычисления
Модель обработки данных, при которой вычисления выполняются на серверах, физически близких к пользователю, а не в центральном дата-центре.
Токен
Минимальная единица текста, которую обрабатывает языковая модель; примерно соответствует слогу или короткому слову.
Sandbox
Изолированная виртуальная среда для безопасного запуска и тестирования кода или приложений без риска для основной системы.

Cloudflare встроила модели OpenAI — GPT-5.4 и Codex — в свою платформу Agent Cloud, которая позволяет компаниям развёртывать ИИ-агентов для автоматизации корпоративных процессов. Агенты могут самостоятельно отвечать клиентам, обновлять внутренние системы и генерировать отчёты — всё это в изолированной среде, готовой к промышленной эксплуатации.

Agent Cloud работает поверх Cloudflare Workers AI — инфраструктуры для запуска ИИ-моделей на периферии сети (edge). Такой подход сокращает задержки: вычисления происходят ближе к конечному пользователю, а не в централизованном дата-центре. Это принципиально для агентных сценариев, где модель должна реагировать в реальном времени — например, в клиентской поддержке или мониторинге транзакций.

Codex — инструмент OpenAI для автоматизации задач разработки — теперь доступен в Cloudflare Sandboxes: изолированной виртуальной среде, где разработчики могут создавать, запускать и тестировать приложения. В ближайшее время Codex появится и непосредственно в Workers AI. По словам менеджера по продукту Codex в OpenAI Рохана Вармы, цель — дать разработчикам возможность развёртывать «готовых к эксплуатации агентов, способных выполнять реальные корпоративные нагрузки в большом масштабе».

Масштаб партнёрства подкреплён цифрами: более 1 млн корпоративных клиентов напрямую используют OpenAI, 3 млн человек еженедельно работают с Codex, а API OpenAI обрабатывают свыше 15 млрд токенов в минуту. Среди компаний, которые уже применяют технологии OpenAI через инфраструктуру Cloudflare, — Walmart, Morgan Stanley, Accenture, Intuit, Thermo Fisher, BNY, State Farm и BBVA.

Интеграция вписывается в более широкую тенденцию: крупные облачные провайдеры — Microsoft Azure, Google Cloud, AWS — давно предлагают доступ к сторонним ИИ-моделям через собственные маркетплейсы. Cloudflare делает ставку на edge-архитектуру как конкурентное преимущество: глобальная сеть из более чем 330 городов позволяет снизить задержку для агентных приложений, критичных ко времени отклика. Технический директор Cloudflare Дейн Кнехт описывает это как «стек следующего поколения, изначально ориентированный на ИИ».
