HPE и NVIDIA расширяют ИИ Factory

Подготовлено редакцией Malakhov AI

NVIDIA Blog·16 июн. 2026 г.·3 минЛабораторииКод

На конференции HPE Discover в Лас-Вегасе, которая завершается 18 июня, NVIDIA и HPE объявили о расширении платформы HPE ИИ Factory: в неё войдут процессор NVIDIA Vera CPU, агентский инструментарий NVIDIA Agent Toolkit и технология конфиденциальных вычислений для всей линейки продуктов.

Кратко

  • —NVIDIA Vera CPU появится в сервере HPE ProLiant Compute DL394 Gen12 в 2027 году — первый процессор, спроектированный под задачи агентного ИИ.
  • —Нью-Йоркская фондовая биржа совместно с Redpanda и HPE уже тестирует Vera CPU раннего доступа.
  • —NVIDIA Agent Toolkit включает открытые модели Nemotron, среду выполнения OpenShell и blueprints NemoClaw для построения мультиагентных систем.
  • —NVIDIA Confidential Computing распространяется на все решения HPE ИИ Factory, защищая данные и модели криптографической аттестацией на каждом этапе.
  • —Партнёрская программа Unleash ИИ расширилась почти на десяток новых участников, в том числе Thales, deepset и Rocket.
Глоссарий · 7 терминов▾
Агентный ИИ
Системы на основе языковых моделей, способные самостоятельно планировать действия, вызывать внешние инструменты и выполнять многошаговые задачи без постоянного участия человека.
Confidential Computing
Технология, защищающая данные и код во время вычислений с помощью аппаратно изолированных доверенных сред выполнения и криптографической аттестации.
DPU (Data Processing Unit)
Специализированный процессор для разгрузки сетевых, хранилищных и задач безопасности с центрального CPU, позволяющий реализовать политику нулевого доверия прямо в сетевом адаптере.
Vera Rubin NVL72
Стоечная система NVIDIA масштаба стойки, объединяющая 72 GPU Rubin и предназначенная для обучения и инференса моделей с более чем 1 триллионом параметров.
Spectrum-X Ethernet
Сетевая платформа NVIDIA, оптимизированная для трафика ИИ-кластеров и обеспечивающая более высокую эффективную пропускную способность по сравнению со стандартным Ethernet.
Blueprint (NemoClaw)
Готовые референсные сценарии развёртывания агентных систем от NVIDIA, ускоряющие создание мультиагентных приложений на базе фреймворка NeMo.
Суверенный ИИ
Концепция развёртывания ИИ-инфраструктуры внутри национального или корпоративного периметра, при которой данные и модели не передаются во внешние облака.

На конференции HPE Discover в Лас-Вегасе NVIDIA и HPE представили обновлённую архитектуру платформы HPE ИИ Factory with NVIDIA. Главные дополнения — процессор NVIDIA Vera CPU, агентский инструментарий NVIDIA Agent Toolkit и расширение технологии конфиденциальных вычислений на весь портфель решений. Партнёры позиционируют обновление как ответ на запрос крупных предприятий, которые готовы переходить от экспериментов с агентным ИИ к его промышленному использованию.

Центральный элемент анонса — NVIDIA Vera CPU, который появится в сервере HPE ProLiant Compute DL394 Gen12 в 2027 году. Vera — первый процессор, спроектированный специально под агентный цикл: вызовы инструментов, оркестрацию задач и обработку данных в реальном времени. Процессор входит в платформу NVIDIA Vera Rubin, уже выпускаемую в виде стоечной системы Vera Rubin NVL72. Эта платформа рассчитана на фронтирные модели с более чем 1 триллионом параметров и поставляется с полным стеком NVIDIA Confidential Computing на каждом чипе. Параллельно HPE добавляет в линейку сервер HPE Compute XD700 на базе NVIDIA HGX Rubin NVL8, поддерживающий до 128 GPU Rubin на стойку. Нью-Йоркская фондовая биржа совместно с Redpanda и HPE уже тестирует Vera CPU в составе DL394 Gen12 — один из первых корпоративных кейсов с этим процессором.

Второй крупный блок — NVIDIA Agent Toolkit, теперь доступный в составе HPE Private Cloud ИИ. Тулкит включает открытые модели NVIDIA Nemotron, защищённую среду выполнения NVIDIA OpenShell и готовые сценарии NVIDIA NemoClaw blueprints. Вместе они образуют то, что партнёры называют «агентной операционной системой»: инструменты мониторинга поведения агентов, применения политик управления и безопасного запуска долгоживущих мультиагентных систем. HPE Private Cloud ИИ добавляет локальную регистрацию агентов — модели, навыки и инструменты проходят проверку на соответствие централизованным политикам безопасности до запуска. Новые возможности HPE Zerto Software позволяют обнаруживать несанкционированные действия агентов и откатываться к чистому состоянию через механизм непрерывной защиты данных. Хранилище HPE Alletra Storage MP X10000, получившее сертификацию NVIDIA-Certified Storage, автоматически применяет метаданные и политики управления к неструктурированным данным, повышая пропускную способность токенов в ИИ-пайплайнах.

Технология NVIDIA Confidential Computing теперь охватывает все решения HPE ИИ Factory — HPE ИИ Factory at Scale, HPE Sovereign ИИ Factory и HPE Private Cloud ИИ — и доступна через сервисы HPE. Конфиденциальные вычисления защищают модели и чувствительные данные непосредственно во время исполнения, выстраивая цепочку доверия через криптографическую аттестацию и шифрование на каждом этапе. Это особенно актуально для суверенных и локальных развёртываний, где данные не могут покидать контролируемый периметр. Сервер HPE ProLiant Compute DL380a прошёл сертификацию в программе NVIDIA-Certified Systems for NVIDIA Confidential Computing. Для защиты сетевого уровня используются NVIDIA BlueField DPU и NVIDIA DOCA: они обеспечивают политику нулевого доверия прямо в кремнии, обнаружение угроз в реальном времени и сетевое шифрование без потери производительности.

На сетевом уровне все решения HPE ИИ Factory at Scale, HPE Sovereign ИИ Factory и HPE Private Cloud ИИ получили поддержку GPU NVIDIA RTX PRO 6000 Blackwell Server Edition, сетевой платформы NVIDIA Spectrum-X Ethernet, контроллеров NVIDIA BlueField-3 DPU и суперсетевых карт NVIDIA ConnectX-8. Каждая система Vera Rubin NVL72 будет поставляться со встроенной сетевой инфраструктурой NVIDIA: контроллерами Vera BlueField-4 DPU, суперсетевыми картами ConnectX-9 и коммутаторами Spectrum-6, обеспечивающими на 60% более высокую пропускную способность по сравнению с обычным Ethernet. Для крупных и суверенных нагрузок HPE также добавляет опцию InfiniBand — NVIDIA Quantum-X800 InfiniBand в составе HPE Cray Supercomputing GX5000, анонсированную ещё на NVIDIA GTC в марте. Партнёрская программа Unleash ИИ расширилась почти на десяток новых участников: Aizen, BridgeTEK, deepset, Deliverance, Faclon Labs, Gallop, Rocket, Supervity, Thales, Trustwise и Vortiqx.
