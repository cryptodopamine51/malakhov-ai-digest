LazyWeb: 257 тысяч экранов для дизайна ИИ-агентов

Подготовлено редакцией Malakhov AI

Habr AI·18 июн.·2 минКод

Бывший product lead Duolingo Али Абуэлатта запустил в мае 2026 года LazyWeb — бесплатный MCP-сервер с 257 тысячами реальных экранов мобильных приложений и сайтов. Инструмент предназначен для семантического поиска дизайн-референсов, чтобы ИИ-агенты не генерировали усреднённые интерфейсы.

  • —Качество выдачи неравномерно: релевантность варьируется от 0.76 до 0.31, много западных приложений.

Глоссарий · 4 термина▾
MCP
Model Context Protocol — протокол, позволяющий ИИ-агентам подключаться к внешним серверам для получения контекста, например, базы референсов.
семантический поиск
Поиск, который понимает смысл запроса, а не просто ищет по ключевым словам или тегам.
эмбеддинги
Векторные представления данных (текста, изображений), позволяющие сравнивать их по смыслу с помощью математических операций.
релевантность
Числовая оценка соответствия найденного результата запросу, часто от 0 до 1.

В мае 2026 года бывший product lead Duolingo Али Абуэлатта запустил LazyWeb — бесплатный MCP-сервер с базой из 257 тысяч реальных экранов мобильных приложений и веб-сайтов. Инструмент предназначен для семантического поиска дизайн-референсов, которые ИИ-агенты могут использовать для генерации интерфейсов. LazyWeb работает с Claude Code, Codex и Cursor, не требует обязательной регистрации и доступен на сайте lazyweb.com/mcp.

Основная идея проекта — заменить генерацию дизайна «по вайбу» на проектирование на основе реальных, проверенных решений. Как поясняет автор, при стандартном подходе ИИ-агент усредняет все примеры из обучающих данных, получая безопасный, но невыразительный результат. LazyWeb позволяет агенту сначала найти, как аналогичную задачу решают живые продукты, а затем предложить несколько вариантов на базе этих референсов. Абуэлатта создал сервер за 77 дней добровольного отпуска, раздражённый низким качеством дизайна, генерируемого агентами.

Технически LazyWeb представляет собой hosted MCP-сервер, использующий Supabase для хранения, vision-модель OpenAI для описания скриншотов, Voyage для создания эмбеддингов и Cohere для переранжирования результатов. Поиск работает по смыслу, а не по тегам: запрос «аналитический дашборд с графиками и боковой навигацией» выдаёт релевантные экраны. База включает как мобильные экраны отдельных приложений (Bumble, Partiful), так и целые веб-страницы с указанием исходного URL.

При этом инструмент имеет ряд недостатков. Качество выдачи неравномерно: рядом с релевантным результатом (0.76) может оказаться малоподходящий (0.31). База насчитывает 26 832 категории, что делает навигацию по ним практически невозможной — реально использовать только поиск. Также заметен перекос в сторону западных приложений. Автор рекомендует обязательно контролировать результаты.

В статье приводится пример успешного использования: автору потребовался UX для админки облачного проекта с множеством сущностей. Вместо недели макетов и итераций он попросил агента сделать несколько вариантов на базе LazyWeb и выбрал лучший с первой попытки.
